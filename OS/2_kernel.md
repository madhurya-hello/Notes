## Core Architecture
### A. User Mode vs Kernel Mode
```text
┌───────────────────────────────────────────────────┐
│                       USER                        │
├───────────────────────────────────────────────────┤
│                   APPLICATIONS                    │
├───────────────────────────────────────────────────┤
│       OPERATING SYSTEM (Kernel & Interface)       │
├───────────────────────────────────────────────────┤
│                     HARDWARE                      │
└───────────────────────────────────────────────────┘
```
### B. System Calls
- You click "Save" inside Microsoft Word
- Word executes a special CPU instruction called a Trap
- **Trap** signals the CPU that kernel assistance is needed
- The **CPU** flips the **Mode Bit** from 1 (User) to 0 (Kernel)
- The **Kernel** verifies permissions and writes the file directly to storage
- The Kernel flips the Mode Bit back to 1 and hands control back to Word
### C. Common System Calls
- **File Management:** `open()`, `read()`, `write()`, `close()`
- **Process Control:** `fork()` (create new process), `exit()`, `wait()`
- **Note:** high-level programming languages use API functions like `printf()` which wrap ow-level system call execution

## Types of Kernel Architecture
### 1. Monolithic Kernel
- all OS services (File System, Memory Management, Device Drivers) run packed inside a single large Kernel space
- **pros:** extremely fast
- **cons:** if a single printer driver crashes, the entire operating system crashes
- **examples:** Linux, Unix
### 2. Microkernel
- only core essentials (CPU Scheduling, Memory Management) remain in the Kernel space
- all drivers and file systems run as isolated modules in User space
- **pros:** if a driver crashes, the OS simply restarts that service
- **cons:** slower performance
- **examples:** QNX, MINIX-3

## Interrupts vs. Software Traps
### A. Interrupt
- generated by hardware devices
- **example:** clicking a mouse, receiving a Wi-Fi packet
### B. Trap
- generated by executing software
- **example:** triggering a system call or encountering an error
